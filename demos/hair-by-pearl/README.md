# Hair by Pearl — Glam Pink Luxury Hair Boutique

A glamorous, Barbie-pink luxury storefront template built for **Hair by Pearl** by **Frame It Agency**.

## Highlights
- **Glam Pink & Rose Editorial Styling**: High-fashion pink gradient palette, Playfair Display typography, and smooth hover animations.
- **Clean Product Cards**: Displays product photo, category badge, hair name, short description (with automatic URL stripping so image links never appear in descriptions), ZAR price, and `+ Add to Cart` button.
- **Google Sheets CSV Sync (`products.csv`)**: Manage products, prices, stock, and images directly from a published Google Sheet.
- **WhatsApp Order Handoff**: Sends itemized cart summaries to `061 610 0885`.
